# GameZone - Proyecto CRUD

## Descripción
Este proyecto es una aplicación desarrollada con Spring Boot que permite realizar operaciones CRUD (Crear, Leer, Actualizar y Eliminar) de videojuegos.

## Arquitectura
- Controller: maneja las peticiones HTTP
- Service: lógica del negocio
- Repository: acceso a base de datos con JPA
